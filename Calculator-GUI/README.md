# Calculator GUI

Java Swing calculator based on the original calculator project.

## Original functionality retained
- ADD
- SUBTRACT
- MULTIPLY
- DIV
- EXIT
- Two-number input and result field

## Added functionality
- CLEAR
- PERCENT (%)
- SQUARE
- SQUARE ROOT
- Calculation history
- Cleaner numeric formatting
- Safer event handling and divide-by-zero/invalid-input messages

## Run
```bash
javac -d target/classes src/main/java/com/example/calculator/App.java
java -cp target/classes com.example.calculator.App
```

The project remains a **GUI application**; it has not been converted to console.
