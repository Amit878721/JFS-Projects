## Projects

### 1. Food Menu
A Java-based Food Menu desktop application built using Java Swing and Maven.

**Main features:**
- User and Admin roles
- User can browse the food menu and place orders
- Admin can view customer orders
- Admin can add, edit, and delete menu items
- Order details include customer name, items, quantity, payment method, and total amount
- Object-Oriented Programming concepts
- Java Swing GUI
- Maven project structure

**Technologies / Concepts:**
- Java
- Object-Oriented Programming
- Interfaces
- Exception Handling
- Java Swing
- Maven
